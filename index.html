When I Grow Up

Personalised AI children's book — print-on-demand

Founders' product

We designed and built a multi-service product pipeline end-to-end for our own consumer brand. Customers answer a short questionnaire on a custom Shopify storefront; the backend generates a unique 38-page illustrated book using Claude for story personalisation and fal.ai for character-consistent illustrations — then renders a print-ready PDF delivered via signed URL.

Pipeline

Shopify → CF Worker → D1 / R2 → Claude API → fal.ai → Playwright PDF → Klaviyo

Approval Flow

Shopify app — customer proof approval workflow

Studio product

A Shopify app for merchants selling personalised or made-to-order products. Replaces the email back-and-forth that custom-product merchants do today: upload a proof against an order, send it to the customer via a signed link, and capture their approval or change request. Built end-to-end in TypeScript on Cloudflare Workers with full OAuth, webhook handling, HMAC verification, and email integration.

Architecture

Shopify OAuth → CF Worker (Hono) → D1 → R2 signed URLs → Resend → Customer page

surfaces — merchant, customer, install
